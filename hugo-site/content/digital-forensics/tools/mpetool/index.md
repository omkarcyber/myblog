<h1 id="mpe-tool">MPE+ Tool</h1>
<p>Mobile Phone Examiner Plus (MPE+)  is a mobile device data review tool that can be used in the field as part of a mobile field unit or in the lab. The data extracted from mobile devices, using MPE+, can be imported into an <a href="https://www.exterro.com/forensic-toolkit">FTK case</a>.</p>

<h3 id="key-features-of-mpe">Key Features of MPE+</h3>
<ul>
<li>Enhanced smart device acquision and analysis capabilities</li>
<li>Support for IOS,Android,Blackberry,Windows phone</li>
<li>ability to acquire data from the e internal memory of 
supported mobile devices and associated media</li>
</ul>
<p>MPE+ is  tool designed to ease mobile device  forensic process.It can perform various forensic data acquision tasks.It can retrive data such as 
equipment/user data, PIM Data, Call Logs, SMS Messages, MMS Messages, Stand-alone Files, Application data,social media data,internet data, GPS data, Non-Latin Characters, Hashing, Case File Data Protection.</p>
<p>Once data is imported into FTK case, it offers more in-depth drill-down, categorization, full-text index searching, and all of this is right alongside other digital evidence collected for a case.</p>
