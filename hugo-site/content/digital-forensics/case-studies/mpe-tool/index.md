<p>Smartphones, mobile phones with more advanced computing capabilities and connectivity than regular mobile phones, came onto the consumer market in the late 90s, but only gained mainstream popularity with the introduction of Apple’s iPhone in 2007.
Today,their are around <a href="https://www.statista.com/topics/840/smartphones/">6.4 billion</a> smartphone sold till date and growing!!!!!</p>
<p>Such alarming smartphone sales  also comes with increase in mobile device Crimes.Nowadays we have dosens of smartphone makers having their own custom operating systems.This is good for consumers but it’s huuuuuuuuge problem for Mobile Forensic Teams worldwide.</p>
<p>It becomes difficult for Mobile Forensic Teams to cope up with such situation. Not because
of workload, but <strong>due to the multitude of mobile forensic solutions on the market
today coupled with the inability to keep up with advances in mobile device technology</strong> .</p>

<h2 id="child-predator-case-solved-using-mpe">Child Predator Case solved using MPE+</h2>
<p>In a one criminal  case involving sexual exploitation of minor. Sgt.
Sneary was tasked with processing a suspect’s iPhone® 4. Suspect used  this phone to communicate with victims in this case, as well as to store sexually explicit images of victims.</p>
<ol>
<li>
<p><!-- raw HTML omitted -->collection<!-- raw HTML omitted --></p>
<ul>
<li>To recover data from victim’s iphone Sgt.Sneary used Cellebrite UFED® along with MPE+</li>
</ul>
</li>
<li>
<p><!-- raw HTML omitted -->Examination<!-- raw HTML omitted --></p>
<ul>
<li>As per NIST framework Data obtained from one tool should be validated by other similar tool. In this Case data obtained by Cellebrite UFED® should be validated by MPE+®</li>
</ul>
</li>
<li>
<p><!-- raw HTML omitted -->Analysis<!-- raw HTML omitted --></p>
<ul>
<li>Sgt.seneary determined the suspect utilized the application <strong>textPlus</strong> to communicate with suspect.He was able to retrive messages sent via the textplus application using MPE+ SQLBuiler.He was able to access application’s SQL database. Additionally, in processing the suspect’s iPhone 4 with the
Cellebrite UFED, Sgt. Sneary utilized MPE+ iLogical support
for iOS® devices to validate the Cellebrite findings.</li>
</ul>
</li>
<li>
<p><!-- raw HTML omitted -->Reporting<!-- raw HTML omitted --></p>
<ul>
<li>Using MPE+ he was able to  present the textPlus messages in a readable format for the jury to see.</li>
<li>Sgt. Sneary recovered a deleted picture the suspect took
of one of the minor victims. In the picture, the suspect’s face was
visible in the background of the image as a reflection in a mirror.
This recovered picture as well as the textPlus messages recovered
with MPE+ SQLBuilder would later be the key evidence
presented at the suspect’s trial.</li>
</ul>
</li>
</ol>
